## Reproduce

Check out the pinned Archify revision, then run these commands from its `archify` directory with Node.js 18 or newer. Replace the paths with your local output paths.

```bash
node bin/archify.mjs validate workflow /path/to/open-detective.workflow.json --quality showcase --json
node bin/archify.mjs deliver workflow /path/to/open-detective.workflow.json /path/to/open-detective.workflow.html --quality showcase --json
node bin/archify.mjs visual-check /path/to/open-detective.workflow.html --json
```
