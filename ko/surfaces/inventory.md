# 노출면 목록 — 어디를 볼 것인가

검수 결과에 따라 **주축(보관처) × 부축1(소유주체) × 부축2(시간)** 구조로 재편했다.
이전의 14개 렌즈는 채널·도구·아티팩트를 한 축에 섞어 이중 계상이 발생했다.
도구(dork·CT조회·API열거·HTTP실측)는 채널이 아니라 **실행 레이어**이며 `ops/discovery.md`에 있다.

## 부축 — 모든 보관처에 곱해지는 두 차원

**소유주체**
| 구분 | 의미 | 조치 경로 |
|---|---|---|
| 자사 | 회사 명의 자산 | 직접 조치 |
| 직원·퇴사자 개인 | 개인 계정에 있는 회사 자료 | 업무지시·takedown. 인사 조치와 **분리**(원칙 15) |
| 제3자 | 수탁사·대행사·제휴사·플랫폼 | **통지만.** 프로빙 금지(원칙 5·12·14) |

**시간**
| 구분 | 의미 |
|---|---|
| 현재 | 지금 서빙 중 |
| 잔존 | 닫아도 남는 것 — 아카이브·커밋 히스토리·레지스트리 이전 버전·AI 인용 |

> 잔존은 별도 채널이 아니라 **모든 채널에 적용되는 차원**이다. "지웠다"는 진술은 잔존 확인 전까지 미확정이다.

## 주축 1 — 코드 저장소
GitHub(저장소·Gist·Pages·Actions 아티팩트·issue 첨부·릴리스·**커밋 히스토리**), GitLab, HuggingFace Spaces.

- **판정 기준**: private는 볼 필요 없다. **배포된 것만** 본다. 그중 `json`·`env`·`yaml`·`csv` 등 **설정·데이터 파일이 든 저장소가 가장 위험**하다.
- **잔존**: 커밋 SHA 직접 조회는 브랜치에서 제거돼도 GC 전까지 유효(실측 200).
- 제외 권고(검수): Gitee·Codeberg·SourceForge·Bitbucket·Azure DevOps — 국내 비개발 조직 사용 가능성 사실상 0.

## 주축 2 — 배포 호스팅
GitHub Pages, Cloudflare Pages, Vercel, Netlify, Firebase, Azure SWA, Render, Railway, Fly.io, Streamlit Cloud, HF Spaces, Glitch, **Google Apps Script 웹앱**, ngrok·Cloudflare Tunnel, Notion 공개페이지.

- **바이브코딩 플랫폼 ★신규**: v0.dev, Lovable, Bolt.new, Base44, Firebase Studio, Replit Agent.
  비개발자가 만든 앱은 **기본 공개 + 키 하드코딩 + 인증 미구현**이 표준이다.
  전사 AI 배포 + 비개발자 조합에서 반드시 산출된다.
- **Supabase / Firebase 규칙 미설정 ★신규**: anon key는 공개가 정상이므로 **키 노출이 아니라 RLS·보안규칙 설정 여부가 판정 기준**이다.
- **페이지가 부르는 자체 데이터 엔드포인트 ★신규**: 엣지 워커·serverless function·스크립트 웹앱·BaaS REST 등
  배포된 페이지가 데이터를 받아오는 주소. **페이지와 그 뒤의 엔드포인트는 별개 자산 2건**이며,
  데이터를 저장소에서 엔드포인트로 옮기는 것은 그 엔드포인트가 익명에 응답하는 한 공개 범위를 줄이지 못한다.
  페이지 소스(`fetch`·XHR 대상, 설정 블록)와 §discovery 5b 네트워크 관찰로 추출해 각각 실측하고,
  **`403`이 나온 것도 포함**해 `ops/verify.md` §"403도 경계가 아니다"로 재측정한다.
- 코드 놀이터(CodePen·JSFiddle·StackBlitz·CodeSandbox·Observable·Glitch)는 개별 점검 대신 **dork 1회로 통합**.

## 주축 3 — 오브젝트 스토리지
S3, GCS, Azure Blob, 네이버클라우드 Object Storage, NHN·카카오클라우드, DO Spaces.

- **판정 3분법(실측 확립)**: `403`=버킷 존재·리스팅 차단(정상) / `404`=없음 / **`200`=리스팅 공개(위험)**.
- 이름 추측은 **후보 생성용일 뿐**이다. 소유 확증 전 자산으로 확정하지 않는다(원칙 12).

## 주축 4 — 문서·시트·폼  ★최우선
Google Drive·Docs·Sheets·Slides 공개링크, **구글폼·네이버폼 응답 스프레드시트**, **구글시트 "웹에 게시"**,
OneDrive·SharePoint, Dropbox, 네이버 MYBOX, **센드애니웨어·WeTransfer·네이버 대용량첨부**,
Notion, Slideshare·issuu·SpeakerDeck, Trello 공개보드, Airtable, Confluence·Jira 공개 인스턴스.

- **국내 협업툴 ★신규**: 네이버웍스·두레이·잔디·플로우·하이웍스·다우오피스.
  Notion·Slack만 점검하면 국내 중견기업 실사용 채널을 통째로 놓친다.
- **"웹에 게시"는 공유 권한과 별개 기능**이다. 권한 점검을 통과하고도 검색엔진에 색인된다.
- **비개발자 조직의 개인정보는 코드가 아니라 스프레드시트에 있다.**

## 주축 5 — AI 산출물  ★신규·최우선
- **대화 공유링크**: ChatGPT·Claude·Gemini·Copilot·Perplexity. 공유 한 번이면 **인증 없는 영구 공개 URL**이 생긴다.
- **AI 회의록**: 클로바노트·다글로·VITO·Otter·Fireflies. 국내 비개발자 사용률 1위이고 **링크공유가 기본 UX**다.
  회의록 원문에 고객명·계약조건·단가가 그대로 들어간다.
- **Custom GPTs·Gemini Gems·NotebookLM**: Knowledge로 올린 사규·단가표·계약서가 프롬프트로 추출된다.
- **AI 문서·슬라이드**: Gamma·Genspark·Felo·Napkin·Lilys. 생성물 기본 노출 설정이 관대하다.
- **생성 서비스 갤러리**: Midjourney는 기본이 공개 갤러리다.
- **AI 검색엔진 잔존 인용**: 삭제한 페이지 내용을 LLM이 계속 인용한다. 삭제 요청 창구가 일반 검색과 다르다.
- **AI 에이전트 설정파일**: `.env`·`.mcp.json`·`CLAUDE.md`·`.cursorrules`·`.claude/settings.json`.
  내부 URL·접속정보·키가 한 파일에 응집돼 2025년 이후 신규 유출 유형 상위다.
- **자사 `llms.txt` 역효과**: GEO 최적화로 만든 `llms.txt`가 숨겨야 할 내부 경로를 AI에 능동 통보할 수 있다.

## 주축 6 — 대화·메신저·커뮤니티
카카오 오픈채팅·단톡방, 채널톡, 네이버 블로그·카페, 티스토리, 브런치, Reddit·StackOverflow,
Discord·Slack 공개 서버, LinkedIn, 채용공고, Blind·잡플래닛, 리멤버.

- **탁송·배차 단톡방 ★업종 최상위**: 배차표·인도확인서에 고객 성명·연락처·주소·차량번호가 통째로 들어가고
  외부 기사에게 이미지로 유통된다. 렌터카 운영구조상 **매일 발생하는 상시 흐름**이다.
- 채용공고·LinkedIn·리멤버·DART는 유출이 아니라 **정찰·배경정보**다. 유출 지표에 섞지 않는다.

## 주축 7 — 인프라 표면
Certificate Transparency(**CertSpotter** — crt.sh는 502로 불안정), 패시브 DNS,
**Shodan InternetDB**(무인증), 열린 포트, TLS 인증서 정합성, robots·X-Robots-Tag.

- **관측·분석 스택 ★신규**: Metabase·Grafana·Kibana·Redash 공개 대시보드, Sentry 공개 이슈, `.map` 소스맵.
  Metabase 공개 질문 링크는 **고객 데이터 원본을 그대로 렌더링**한다.
- **API 문서·협업 ★신규**: Postman 공개 워크스페이스, Swagger·OpenAPI, Zapier·Make 시나리오, 웹훅 URL.
- **자산 상호연결 피벗 ★신규**: GA·GTM ID, AdSense ID, 공용 이메일·전화번호 역검색, favicon hash.
  대행사가 만든 **미인지 사이트**를 찾는 가장 효율적 수단이다.
- **사칭·타이포스쿼팅 ★신규**: 유사 도메인. 렌터카는 가짜 사이트 계약금 편취가 다발 업종이며 CT로 탐지 가능하다.
- **국내 표준 스택 포털**: `mail.`·`erp.`·`groupware.` 서브도메인이 CT 로그로 드러난다.

## 주축 8 — 제3자·공급망  ★신규 축
수탁사·대행사·정비·탁송·홈페이지 제작사·캐피탈·공제조합·보험사.

- **자사 개인정보처리방침의 수탁사 목록이 그대로 점검 대상 리스트**가 된다.
- **광고 대행사 랜딩페이지·리드수집 폼 ★최우선**: 대행사가 만든 그림자 랜딩(아임웹·카페24·무료호스팅)의
  DB수집 폼이 업계 개인정보 유출 상위 경로다. **자사 자산대장에 없어 점검 사각**이다.
- **통지가 정답이다.** 추가 프로빙·하베스팅을 하지 않는다(원칙 5·12·14).
- 수탁자라면 위탁자인 자사에 관리·감독 책임이 있어 자사 의무 문제로 번진다.

## 주축 9 — 업종 채널 (렌터카·모빌리티)  ★신규 축
- **중고차 플랫폼 반납차 매물**(엔카·KB차차차·헤이딜러·첫차): 매물 사진에 번호판·차대번호·정비이력.
- **차량관제·텔레매틱스 대시보드**: 무인증 노출 시 전 차량 실시간 위치 = 고객 위치추적. 위치정보법까지 겹쳐 피해 최대.
- **렌터카 중개 플랫폼**(카모아·네이버 렌터카 등): 제3자 플랫폼에 재고·단가·문의가 축적되고 리뷰란에 계약서 사진이 붙는다.
- **블랙박스·사고영상 업로드**: 번호판·얼굴 미모자이크.
- **차량 사진 EXIF**: 차고지·정비소 GPS, 촬영 단말 식별정보.
- **공공데이터포털 자동차대여사업 등록현황**: 사업자별 보유대수·차량번호가 자산 인벤토리를 외부에 완성해 준다.

## 횡단 단계 — 파일 내부 검사  ★신규
목록은 "파일을 **어디서** 찾나"만 다뤘고 "찾은 파일 **안에** 무엇이 남았나"가 없었다.
주축 1~9에서 확보한 파일에 대한 **필수 후속 단계**다.

- 엑셀: 숨김 시트·숨김 행·피벗캐시·필터된 데이터
- PDF: 검은칠(redaction) 실패 — 아래 원문이 그대로 남음
- HWP·HWPX: 작성자·소속·내부 NAS 경로·편집 이력
- 이미지: EXIF GPS·단말 정보
- Office 전반: 작성자·수정자·회사명 메타데이터

> 단, **원본을 복제해 로컬에 보관하지 않는다**(원칙 10). 검사는 최소·마스킹·조치 후 파기.

## 우선순위 — 발생확률 × 피해크기

| # | 채널 | 근거 |
|---|---|---|
| 1 | 구글 드라이브·시트 공개링크 + **폼 응답시트** + 웹에 게시 | 비개발자 조직의 개인정보 소재지. "링크 공유" 오설정 확률이 사실상 1 |
| 2 | 탁송·배차 단톡방·개인 단말 유통 | 매일 발생하는 상시 흐름. 면허번호는 고유식별정보 |
| 3 | AI 대화 공유링크 + AI 회의록 | 전사 AI 배포 중 = **지금 생성되고 있다.** 통제수단 부재 |
| 4 | 광고 대행사 랜딩·리드수집 폼(제3자) | CPC 집행 실측 확인. 자산대장에 없는 사각 |
| 5 | **공식 도메인의 비의도 노출**(업로드 디렉터리·백업파일·스테이징) | `dev.<회사도메인>` 실측이 증거. 발견 비용 최저 |
| 6 | 수탁사·제작사 등 공급망 서버 | 제휴사 도메인에서 자사 PDF가 실제로 발견됨 |
| 7 | 바이브코딩 앱 + Supabase·Firebase 규칙 미설정 | 비개발자 + AI 도구의 필연적 산출물. DB 전체가 열림 |
| 8 | 아카이브 잔존(Wayback CDX) | 실측 PASS·저비용. "이미 지웠다"가 거짓임을 증명하는 유일 수단 |
| 9 | 퇴사자·직원 개인계정 잔존 | 오프보딩 미비가 최다 사고 원인. 탐지 난이도 높음 |
| 10 | 문서 내부 잔존(숨김시트·redaction 실패·HWP 메타데이터) | 한 건이 대량 레코드를 담을 수 있어 피해 기댓값이 큼 |
| 11~13 | 차량관제 대시보드 · 공개 버킷 · 사칭 도메인 | 피해 최대이나 발생확률 미확인 / 판정법 확립됨 / 업종 사기 다발 |

## 제외 — 목록에서 뺀 것과 이유
**동작하지 않는 것을 목록에 두면 거짓 음성을 만든다.**

| 대상 | 사유 |
|---|---|
| grep.app·searchcode·publicwww·Google 캐시·archive.today | 실측에서 차단·폐지·유료·레이트리밋 |
| Shodan 정식 API·Censys·ZoomEye·FOFA·BinaryEdge·VirusTotal·HIBP 도메인검색 | 전부 유료키(401 실측). InternetDB로 대체 |
| Common Crawl | Wayback과 중복도 높고 파싱 비용 큼 |
| GH Archive | 시간당 21MB. 목적 대비 비용 과대 |
| Gitee·Codeberg·SourceForge·Bitbucket·Azure DevOps | 국내 비개발 조직 사용 가능성 0 |
| Maven·JitPack·NuGet·RubyGems·crates.io·Go proxy | 언어스택 무관 |
| Kaggle·Colab·HF models·datasets | 데이터사이언스 조직 부재. **HF Spaces만 유지** |
| Baidu·Yandex | 한국 렌터카 인덱싱 기여 미미 |
| Padlet·Miro·Canva·Zoom 녹화 | 국내 사용률 낮음 → **채널톡·클로바노트로 교체** |
| DART | 합법 공시. 유출 아닌 **배경정보**로 격하 |
| TruffleHog·Gitleaks | 채널이 아니라 도구. 미설치 상태이며 스캔 대상 로컬 저장소 부재 |

**유지**: 당근·중고나라, 나라장터·공공기관 공고첨부, Trello 공개보드 — 저비용이므로 남긴다.
